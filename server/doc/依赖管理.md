# 依赖管理

## 概述

KAce应用管理系统采用Gradle的Version Catalog功能进行依赖管理，通过`libs.versions.toml`文件集中管理所有依赖版本，提高依赖管理的可维护性和一致性。

## Version Catalog

### 文件位置

依赖版本定义文件位于项目根目录的`gradle/libs.versions.toml`。

## 在项目中使用

### 在build.gradle.kts中引用依赖

```kotlin
plugins {
    alias(libs.plugins.kotlin.jvm)
    alias(libs.plugins.kotlin.serialization)
}

dependencies {
    // 单个依赖引用
    implementation(libs.kotlin.stdlib)
    implementation(libs.kotlin.reflect)
    implementation(libs.kotlinx.coroutines.core)
    
    // 使用依赖包
    implementation(libs.bundles.ktor.server)
    implementation(libs.bundles.exposed)
    implementation(libs.bundles.logging)
    
    // 数据库驱动（根据配置选择）
    runtimeOnly(libs.mysql.connector)
    // runtimeOnly(libs.postgresql.jdbc)
    
    // 存储相关（根据配置选择）
    implementation(libs.minio)
    implementation(libs.tencentcloud.cos)
    implementation(libs.aliyun.oss)
    
    // 测试依赖
    testImplementation(libs.bundles.testing)
}
```

### 在settings.gradle.kts中启用Version Catalog

```kotlin
dependencyResolutionManagement {
    versionCatalogs {
        create("libs") {
            from(files("gradle/libs.versions.toml"))
        }
    }
}
```

## 多模块项目结构

KAce应用管理系统采用多模块结构，每个模块都使用相同的依赖管理方式：

```
KAce/
├── gradle/
│   └── libs.versions.toml
├── build.gradle.kts
├── settings.gradle.kts
├── server/
│   ├── core/
│   │   └── build.gradle.kts
│   ├── api/
│   │   └── build.gradle.kts
│   ├── plugin-sdk/
│   │   └── build.gradle.kts
│   └── build.gradle.kts
└── client/
    ├── common/
    │   └── build.gradle.kts
    ├── web/
    │   └── build.gradle.kts
    ├── android/
    │   └── build.gradle.kts
    └── build.gradle.kts
```

## 依赖更新策略

1. **定期检查更新**：使用Gradle的依赖更新检查功能，定期检查依赖是否有新版本
   ```bash
   ./gradlew dependencyUpdates
   ```

2. **版本兼容性测试**：更新依赖版本前，先在开发环境进行充分测试，确保兼容性

3. **遵循语义化版本**：依赖版本遵循语义化版本规范（SemVer），便于判断兼容性

4. **保持依赖最小化**：避免引入不必要的依赖，减少潜在的兼容性问题

## 插件依赖管理

插件开发时，应该使用与核心系统相同的依赖版本，避免版本冲突：

```kotlin
// 插件build.gradle.kts
plugins {
    alias(libs.plugins.kotlin.jvm)
}

dependencies {
    compileOnly(libs.kotlin.stdlib)
    compileOnly(libs.kotlin.reflect)
    compileOnly(project(":server:plugin-sdk"))
    
    // 插件特有依赖
    implementation("com.example:some-library:1.0.0")
}
```

## 优势

1. **集中管理**：所有依赖版本在一个文件中管理，便于维护
2. **版本一致性**：确保所有模块使用相同版本的依赖
3. **依赖分组**：通过bundles功能将相关依赖分组，简化引用
4. **IDE支持**：现代IDE（如IntelliJ IDEA）对Version Catalog提供良好支持，包括自动完成和版本提示
5. **可读性**：TOML格式比传统Gradle脚本更易读易维护
