# 权限模块设计

## 功能概述

权限模块是系统安全的核心部分，负责管理系统中的权限、菜单和API。主要功能包括：

1. 权限的创建、修改、删除
2. 菜单的创建、修改、删除
3. API的创建、修改、删除
4. 权限与菜单、API的关联管理

suspend fun buildMenuTree(menus: List<Menu>, parentId: UUID? = null): List<MenuTree> {
    return menus.filter { it.parentId == parentId }
        .sortedBy { it.sort }
        .map { menu ->
            MenuTree(
                id = menu.id,
                name = menu.name,
                code = menu.code,
                path = menu.path,
                icon = menu.icon,
                sort = menu.sort,
                children = buildMenuTree(menus, menu.id)
            )
        }
}

### API权限校验

```kotlin
suspend fun checkApiPermission(path: String, method: HttpMethod, userId: UUID): Boolean {
    // 查找匹配的API
    val api = apiRepository.findByPathAndMethod(path, method) ?: return false
    
    // 如果API没有关联权限，则允许访问
    val permissionId = api.permissionId ?: return true
    
    // 获取权限编码
    val permission = permissionService.getPermissionById(permissionId) ?: return false
    
    // 检查用户是否有该权限
    return permissionChecker.hasPermission(userId, permission.code)
}
```

### 权限缓存

为了提高权限检查的性能，系统使用缓存存储用户权限：

```kotlin
class CachedPermissionChecker(
    private val userService: UserService,
    private val rolePermissionService: RolePermissionService,
    private val cache: Cache
) : PermissionChecker {
    
    override suspend fun hasPermission(userId: UUID, permissionCode: String): Boolean {
        val cacheKey = "user:$userId:permission:$permissionCode"
        
        // 尝试从缓存获取
        cache.get<Boolean>(cacheKey)?.let { return it }
        
        // 缓存未命中，执行权限检查
        val result = checkPermissionInternal(userId, permissionCode)
        
        // 将结果存入缓存，有效期1小时
        cache.put(cacheKey, result, Duration.ofHours(1))
        
        return result
    }
    
    private suspend fun checkPermissionInternal(userId: UUID, permissionCode: String): Boolean {
        val user = userService.getUserById(userId) ?: return false
        if (user.status != UserStatus.ENABLED) return false
        
        val roles = userService.getUserRoles(userId)
        return roles.any { role ->
            if (role.status != RoleStatus.ENABLED) return@any false
            rolePermissionService.hasPermission(role.id, permissionCode)
        }
    }
    
    override suspend fun clearCache(userId: UUID) {
        cache.removeByPattern("user:$userId:permission:*")
    }
}
```

## 安全考虑

1. **权限粒度**：系统支持细粒度的权限控制，可以精确到具体API操作
2. **权限分离**：将权限与菜单、API分离，便于灵活配置
3. **权限缓存**：使用缓存提高权限检查性能，同时确保缓存及时更新
4. **权限继承**：支持通过角色继承实现权限继承，简化权限管理
5. **权限审计**：记录权限变更日志，便于安全审计
