# 用户模块设计

## 功能概述

用户模块是系统的基础模块，负责用户的身份认证和授权管理。主要功能包括：

1. 用户注册、登录、注销
2. 用户信息管理
3. 用户角色分配
4. 密码管理（重置、修改）
5. 用户状态管理（启用/禁用）

## 数据模型

## 实现细节

### 密码加密

使用BCrypt算法进行密码加密，确保密码安全存储：

```kotlin
object PasswordEncoder {
    private val bcrypt = BCrypt()
    
    fun encode(rawPassword: String): String {
        return bcrypt.hashpw(rawPassword, bcrypt.gensalt())
    }
    
    fun matches(rawPassword: String, encodedPassword: String): Boolean {
        return bcrypt.checkpw(rawPassword, encodedPassword)
    }
}
```

### 用户认证流程

1. 客户端发送用户名和密码到服务端
2. 服务端验证用户名和密码
3. 验证通过后，生成JWT令牌
4. 将令牌返回给客户端
5. 客户端后续请求携带令牌进行身份验证

```kotlin
fun generateToken(user: User): String {
    val now = Date()
    val expiryDate = Date(now.time + jwtExpirationMs)
    
    return Jwts.builder()
        .setSubject(user.id.toString())
        .setIssuedAt(now)
        .setExpiration(expiryDate)
        .signWith(SignatureAlgorithm.HS512, jwtSecret)
        .compact()
}
```

### 用户授权流程

1. 拦截请求，获取JWT令牌
2. 验证令牌有效性
3. 从令牌中获取用户ID
4. 加载用户信息和权限
5. 验证用户是否有权限访问请求的资源

```kotlin
suspend fun hasPermission(userId: UUID, permissionCode: String): Boolean {
    val user = userService.getUserById(userId) ?: return false
    if (user.status != UserStatus.ENABLED) return false
    
    val roles = userService.getUserRoles(userId)
    return roles.any { role ->
        rolePermissionService.hasPermission(role.id, permissionCode)
    }
}
```

## 安全考虑

1. **密码安全**：使用BCrypt等强哈希算法存储密码，避免明文存储
2. **会话管理**：使用JWT令牌进行无状态会话管理，设置合理的过期时间
3. **防暴力破解**：实现登录失败次数限制和IP封禁机制
4. **敏感操作保护**：敏感操作（如修改密码、分配角色）需要二次验证
5. **日志审计**：记录用户登录、注销和敏感操作的日志
