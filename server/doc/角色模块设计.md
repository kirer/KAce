# 角色模块设计

## 功能概述

角色模块负责系统中角色的管理和权限分配。主要功能包括：

1. 角色的创建、修改、删除
2. 角色与应用的关联管理
3. 角色与权限的关联管理
4. 角色状态管理（启用/禁用）

interface RoleService {

interface RoleApplicationService {
    suspend fun assignApplications(roleId: UUID, applicationIds: List<UUID>, updatedBy: UUID): Boolean

## 实现细节

### 角色权限检查

```kotlin
suspend fun checkPermission(userId: UUID, permissionCode: String): Boolean {
    val user = userService.getUserById(userId) ?: return false
    if (user.status != UserStatus.ENABLED) return false
    
    val roles = userService.getUserRoles(userId)
    return roles.any { role ->
        if (role.status != RoleStatus.ENABLED) return@any false
        rolePermissionService.hasPermission(role.id, permissionCode)
    }
}
```

### 角色继承

系统支持角色继承，一个角色可以继承另一个角色的所有权限：

```kotlin
data class Role(
    // ... 其他字段
    val parentId: UUID? = null // 父角色ID
)

suspend fun getAllPermissions(roleId: UUID): Set<Permission> {
    val result = mutableSetOf<Permission>()
    val role = getRoleById(roleId) ?: return result
    
    // 添加当前角色的权限
    result.addAll(rolePermissionService.getRolePermissions(roleId))
    
    // 递归添加父角色的权限
    role.parentId?.let {
        result.addAll(getAllPermissions(it))
    }
    
    return result
}
```

### 角色应用权限控制

角色只能分配其有权访问的应用的权限：

```kotlin
suspend fun canAssignPermission(roleId: UUID, permissionId: UUID): Boolean {
    val permission = permissionService.getPermissionById(permissionId) ?: return false
    val roleApplications = roleApplicationService.getRoleApplications(roleId)
    
    return roleApplications.any { it.id == permission.applicationId }
}
```

## 安全考虑

1. **最小权限原则**：角色应该只被赋予完成其任务所需的最小权限集
2. **职责分离**：敏感操作应该需要多个角色的协作才能完成
3. **权限审计**：定期审计角色权限，确保符合安全策略
4. **角色生命周期管理**：角色不再需要时应及时禁用或删除
